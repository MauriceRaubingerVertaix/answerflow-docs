AnswerFlow: Questions, Answers & Zero-Egress AI Q&A for Confluence

Turn Confluence Cloud into a fast, governed internal StackOverflow—complete with full-text search across answers, granular Ask vs. Answer permissions, a Live FAQ Accordion Macro, 1-click Promote-to-Page, and native Zero-Egress AI Answer Deflection.

Zero-Egress AI Deflection

Powered natively by Atlassian Forge LLMs inside Atlassian's trust boundary. Checks existing Q&A and Confluence pages (strictly honoring user permissions) before a duplicate question is ever posted.

Full-Text Search & Duplicate Merge

Searches question titles, descriptions, tags, and every answer body. Moderators can merge duplicate threads cleanly without losing votes or tags.

Granular RBAC & Controlled Tags

Separately control who can submit questions, who can answer, who can pin curated FAQs, and who can create new tags—plus global tag rename/merge and a built-in Compliance Audit Trail.

Live FAQ Accordion Macro

Embed questions and verified answers directly on any Confluence page via /AnswerFlow, with an optional inline Ask a Question composer.

5-Minute Quickstart

  1. Install AnswerFlow from the Atlassian Marketplace into your Confluence Cloud site.
  2. Open Apps → AnswerFlow Q&A (site-wide hub) or open any Space sidebar → Space Q&A.
  3. Click Load Sample Q&A to preview an answered FAQ immediately, or click Ask a Question to post your first real question.
  4. Click Check Existing Answers (Zero-Egress AI) inside the composer to test grounded zero-egress deflection.
  5. Type /AnswerFlow inside any Confluence page editor to embed a live FAQ Accordion filtered by tag or pinned FAQ order.
  6. Site administrators and moderators can configure RBAC roles, controlled tags, daily AI quotas, exports, and audit logs under the Governance & Migration tab.

Migrating from Questions for Confluence or Legacy Connect Q&A Apps

With Atlassian Connect reaching End of Support on January 31, 2027, moving your team's Q&A history into a pure Runs on Atlassian Forge app takes minutes:

  1. Export your existing questions and answers into the simple AnswerFlow JSON bundle format below.
  2. Open AnswerFlow Q&A → Governance & Migration.
  3. Paste your JSON bundle into Import Questions Bundle (JSON) and click Run Migration Import.
{
  "questions": [
    {
      "spaceKey": "ENG",
      "title": "How do I request production VPN access?",
      "body": "Need VPN credentials for staging and production.",
      "tags": ["onboarding", "vpn"],
      "isFaq": true,
      "faqOrder": 1,
      "answers": [
        {
          "body": "Open an IT Access ticket in JSM with manager approval.",
          "authorName": "IT Operations",
          "accepted": true
        }
      ]
    }
  ]
}

Permissions & Least-Privilege Scopes

Confluence Scope Why AnswerFlow Needs It
storage:appStores questions, answers, governance settings, and audit logs inside Atlassian-hosted Forge Storage.
search:confluenceRuns native CQL searches as the current user (asUser()) during AI Answer Deflection so restricted pages are never exposed.
read:page:confluenceReads accessible page titles/snippets returned by user-scoped search.
write:page:confluenceCreates a clean Confluence page when a moderator clicks Promote Accepted Answer to Page.
read:space:confluencePopulates the target Space picker when promoting answers to documentation.
read:confluence-userDisplays author names and verifies Confluence administrator permissions.
